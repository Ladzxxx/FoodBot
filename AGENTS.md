# Правила работы над FoodBot

- Развивать существующий шаблон Python/aiogram в этом проекте.
- Полностью исключать `Archive` из чтения, поиска, проверок и изменений. Не запускать рекурсивные проверки всего проекта.
- Писать простой, понятный код: небольшие функции, понятные имена, обычные условия и циклы. Нетривиальные решения кратко комментировать на русском.
- Значительное усложнение архитектуры сначала обсуждать с пользователем и ждать подтверждения. Не добавлять ORM, фабрики, дополнительные слои или универсальные системы. Классы добавлять только при необходимости.
- Группировать обработчики по функционалу. Клавиатуры, SQLite и состояния держать отдельно по назначению. Не складывать всё в один файл и не создавать файл на каждую функцию.
- Текущий этап: нейтральный календарь без будущих дат; дневник сна, стабильности настроения, боли, лекарств и заметок. Пользователь подтвердил план `Readmes/DAY_FLOW_PLAN.md`: две новые таблицы SQLite и модуль `day_storage.py` с обычными функциями.
- Просмотр, навигация и статистика не записывают ответы. По последнему запросу каждый ответ нового дневника сохраняется сразу. Отмена сохраняет записанный прогресс; незавершённый опрос продолжается с очередного вопроса.
- Сохранять старые «Да/Нет» и оценки 1–7 отдельно, не преобразовывать их в новую шкалу 1–10. Данные разделять по пользователю и дате.
- Старую фоновую рассылку шаблона не запускать. Пользователь разрешил персональные напоминания: после выбранного часа, при 24 часах без завершённой записи, не более одного за местный день. Другие вопросы, графики и последующие этапы добавлять только после подтверждения пользователя.
- Документация проекта находится в `Readmes`. Обновлять карту файлов, места изменения вопросов, кнопок, отображения дня, статистики и инструкцию запуска в `Readmes/README.md`.
- Проверять основные сценарии, сообщать, что действительно проверено, кратко объяснять изменения и останавливаться для проверки пользователем.
- Не выводить токен и содержимое `.env`. Не включать токен, виртуальное окружение или базу в Git.
- Текущий запрос добавляет команды из любого диалога, повторную настройку профиля, быстрое UTC-смещение, выбор продолжить/очистить черновик, общую статистику и /meal. Использовать текущие модули и обычные функции; для еды добавить одну таблицу SQLite.
- Еда фиксируется в местных дате и времени на момент /meal, описание не длиннее 50 символов. Запись еды не сбрасывает напоминания: это отдельно подтвердил пользователь.
- Редактирование настроек не меняет действующий профиль до завершения. Изменение часового пояса сохраняет работу напоминаний и защиту от повторной отправки.
- Помечать места изменения интерфейсных текстов и подписей комментарием `# CAN CHANGE TEXT`.
- Новый запрос: /makenote с последними восемью датами и переходами к записи сегодня/вчера; время последнего ответа хранить в diary_entries.updated_at без выдуманных времён для старых записей.
- Отметки завершённых дней по числу невыполненных условий: 0 — ✅, 1 — 🟨, 2 — 🟧, 3 и более — 🟥. Незавершённый день — 📝, без ответов — без отметки. В календаре легенду не показывать.
- После каждого принятого ответа настройки показывать «Wrote the answer» и значение. Подписи кнопок начинать с заглавной буквы.
- Подтверждённое уточнение: отход ко сну — от полудня предыдущего дня до полудня выбранного (bedtime_day -1/0), пробуждение — 00:00–24:00 выбранного дня. Максимум 36 часов. При отрицательной длительности не сохранять ответ и повторять вопрос с локализованной ошибкой «Sleep duration cannot be negative.». Старым записям сохранять день старого вопроса (-1).
- Постоянная Reply Keyboard содержит /meal, /callendar, /settings. Команда календаря — только /callendar; использовать это написание в обработчиках, сообщениях и документации.
- Текущие пять условий отметок: сон >= 7 часов, удовлетворённость сном >= 7, настроение >= 7, записей еды за дату >= 2, отход ко сну до 23:00 предыдущего дня. Все экраны считают отметку одинаково по сохранённым данным.
- В статистике показывать средние, числа оценок ниже 7, дни с болью, Excellent days и Meal notes. Кнопка предыдущего месяца подписана его английским названием; Meal statistics пока только подтверждает нажатие.
- Интерфейс на ru/en из user_profiles.language, включая месяцы и дни недели. Пропущенный ответ — ___; важные заголовки выделять жирным с экранированием пользовательского текста.
- Сообщения настройки используют готовые изображения из Images: helloimage — приветствие, gender — пол, bdayyear — год рождения, timezones — UTC-смещение, seeyousoon — итог. Текст — в подписи, inline-кнопки сохраняются. Имена находятся в Forms/profile.py, пути считаются от папки проекта.
- Последнее уточнение: общая заметка дня — последний вопрос, до 200 символов; в выбранной дате показывать её под Meals. Старые длинные заметки сокращать только на экране. Кнопку View full entry не показывать, обработчик и данные сохранять. Только красная отметка завершённого дня с ache=Yes заменяется на 🆘. Напоминание Make a note about DD.MM.YYYY: утро — вчера, вечер — сегодня по UTC-смещению пользователя.
- Переводы — статические TEXTS в Locales/ru.py и Locales/en.py, функция t() в localization.py; без API, middleware и глобального текущего языка. Ключи и подстановки должны совпадать. Язык получать из профиля и передавать в функции текста/клавиатур; t() не читает SQLite. Запасной язык — русский. Только для первого приветствия без сохранённого выбора: кириллица в имени Telegram — ru, латиница — en, иначе ru. Не сохранять догадку вместо явного выбора. /language меняет только язык; /settings хранит черновой язык до завершения, напоминания используют сохранённый. Коды ответов, callback_data, состояния и пользовательские тексты не переводить.
- Команда /notif удалена. Пол и год рождения временно отключены комментариями в PROFILE_QUESTIONS; сохранить код, изображения и прежние значения для возврата. /settings без этих полей не обнуляет их в базе. Excel использует текущий сохранённый язык при нажатии, включая старую кнопку. Поддерживать .env.example без секретов, исключения Git и requirements.txt; коммит выполняет владелец. Не переписывать историю Git без отдельного указания.
